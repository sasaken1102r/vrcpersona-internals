# Contributing

## 日本語

このリポジトリは、VRCPersona 本体（クローズドソース）に含まれるファイルを、検証可能にするために公開しているものです。本体と内容を同期しています。

### Issue

受け付けています。

- 実装についての指摘
- README の記述と実装が異なる場合の報告
- 質問・誤記の指摘

日本語・英語のどちらでも構いません。

<strong>ただし、実際に悪用できる脆弱性（暗号化を回避できる、認証情報を読み取れる等）を見つけた場合は、公開の Issue ではなく [SECURITY.md](./SECURITY.md) の窓口へご連絡ください。</strong>修正が行き渡る前に手口が公開されると、他の利用者が危険にさらされます。

### Pull Request

コードの Pull Request は受け付けていません。

このリポジトリのファイルは、クローズドソースである VRCPersona 本体にも同じものが含まれています。GPLv3 のもとで提供されたコードを本体（非公開）へ取り込むことはできないため、マージできない Pull Request を放置することになります。

変更の提案は Issue に記載してください。内容を確認のうえ、こちらで実装します。

## English

This repository publishes files that are part of the (closed-source) VRCPersona app so that they can be independently verified. Its contents are kept in sync with the app.

### Issues

Accepted.

- Comments on the implementation
- Reports of discrepancies between the README and the code
- Questions and typo reports

Japanese or English is fine.

**However, if you find an exploitable vulnerability (bypassing the encryption, reading credentials, and so on), please use the contact points in [SECURITY.md](./SECURITY.md) rather than a public issue.** Publishing the method before a fix has propagated puts other users at risk.

### Pull Requests

Code pull requests are not accepted.

The files here are also part of VRCPersona itself, which is closed source. Code contributed under GPLv3 cannot be incorporated into that closed codebase, which would leave such pull requests unmerged indefinitely.

Please describe proposed changes in an Issue instead. They will be reviewed and implemented here.
